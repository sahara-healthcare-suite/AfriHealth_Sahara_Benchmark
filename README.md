# AfriHealth Sahara Benchmark

This repository archives the previous benchmark summary for the Sahara
CodeSwitch Africa Challenge.

## Report

`evaluation_report_summary.json` records a comparison dated 2026-09-11 for
Intron AfriHealth MultiBench v1.2. It reports Intron Sahara v2.5, OpenAI Whisper
Medium, and Meta OmniCTC metrics. `BENCHMARK_RESULTS.md` also includes fixture
results; those are illustrative and must not be confused with measured results.

## Limitations

The summary does not include sample count, per-sample predictions, audio
hashes, model settings, or metric definitions. Its aggregate values cannot be
independently reproduced from the files in this repository. Treat them as
previously reported results, not a new or independently verified evaluation.

No dataset audio or credentials are included. AfriSwitch is gated; follow its
license and access terms before using or sharing data.
